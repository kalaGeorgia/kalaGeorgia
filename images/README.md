# Фото

Реальные фото загружены и подключены. Слайдер в блоке «Автопарк» и фон hero
ссылаются на файлы ниже (см. `index.html`, атрибуты `data-slot`).

| Файл | Слот | Описание | Где используется |
|---|---|---|---|
| `slot-1-interior-ambient.jpg` | 1 | Салон с фиолетовой ambient-подсветкой на потолке (вид от передних сидений назад) | Слайдер, первый кадр |
| `slot-2-exterior-front.jpg` | 2 | Экстерьер 3/4 спереди, чёрный кузов, каменная стена на фоне | Слайдер |
| `slot-3-side-open-doors.jpg` | 3 | Боковой профиль с открытыми дверями, видно салон и экстерьер одним кадром | Слайдер + фон Hero (тёмный градиент поверх) |
| `slot-4-dashboard-wood.jpg` | 4 | Передняя панель и руль с деревянной отделкой (снято от 3-го ряда) | Слайдер |
| `slot-5-trunk-open.jpg` | 5 | Открытый багажник (3-й ряд поднят) | Слайдер |
| `bonus-exterior-rear.jpg` | 6 (бонус) | Экстерьер сзади, 3/4 | Слайдер, доп. слайд |

Кадрирование в слайдере — по центру через `object-fit: cover` (соотношение 4:3).

## Чего не хватает для следующей фотосессии
- Водитель в деловой одежде у машины (триггер для B2B-аудитории)
- Чистый экстерьерный кадр без открытых дверей на нейтральном фоне (для карточек каталога)
- Вечерний кадр с ambient-подсветкой в темноте
